# Fares Elzouhiry — Portfolio

موقع شخصي لفارس الزهيري: مشاريعه (Juster للجامعة، Alliance، Sport Barbecue، ايرتك جاهز، مدرسة الفرسان)، والمستندات، والمهارات. بالعربي والإنجليزي.

## الملفات

| الملف | فيه إيه |
|---|---|
| `index.html` | الموقع كله: HTML و CSS و JavaScript في ملف واحد |
| `img/` | صور المشاريع |
| `serve.ps1` | سيرفر صغير علشان تشوف الموقع على جهازك |

## تشوفه على جهازك

افتح PowerShell في الفولدر ده واكتب:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

وبعدين افتح http://localhost:8765

لو فتحت `index.html` بالدبل كليك هيشتغل، بس الدايرة الـ 3D اللي فوق مش هتظهر (المتصفح بيمنع الصور في الـ 3D من غير سيرفر)، وهيظهر مكانها صور ثابتة.

## ترفعه على النت (GitHub Pages)

1. اعمل repo جديد على GitHub وارفع فيه `index.html` وفولدر `img`.
2. من Settings ← Pages اختار الفرع `main` واضغط Save.
3. الموقع هيبقى على `https://<اسمك على GitHub>.github.io/<اسم الـ repo>/`
