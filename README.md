# Fares Elzouhiry — Portfolio

موقع شخصي لفارس الزهيري على شكل عالم 3D فاتح: وانت بتعمل سكرول، الكاميرا بتطير من مشروع للتاني (Juster للجامعة، Alliance، Sport Barbecue، ايرتك جاهز، مدرسة الفرسان، والمستندات)، وفي الآخر كل المشاريع بتلف حواليك. بالعربي والإنجليزي.

## الملفات

| الملف | فيه إيه |
|---|---|
| `index.html` | الموقع كله: HTML و CSS و JavaScript (و Three.js للـ 3D) في ملف واحد |
| `img/` | صور المشاريع |
| `serve.ps1` | سيرفر صغير علشان تشوف الموقع على جهازك |

## تشوفه على جهازك

افتح PowerShell في الفولدر ده واكتب:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

وبعدين افتح http://localhost:8765

لو فتحت `index.html` بالدبل كليك هيشتغل، بس من غير العالم الـ 3D (المتصفح بيمنع الصور في الـ 3D من غير سيرفر)، وهيظهر مكانه نفس الكلام والصور في صفحة عادية.

## لينكات لمشروع معيّن

ممكن تبعت لينك يفتح على مشروع بعينه: `#uni` · `#alliance` · `#models` · `#bbq` · `#airtech` · `#school` · `#docs` · `#contact`

## ترفعه على النت (GitHub Pages)

1. ارفع `index.html` وفولدر `img` على الـ repo.
2. من Settings ← Pages اختار الفرع `main` واضغط Save.
3. الموقع هيبقى على `https://<اسمك على GitHub>.github.io/<اسم الـ repo>/`
